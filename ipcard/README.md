# IP Card

This directory contains metadata describing the SSCU for IP catalog and
integration tooling.

- [`safety-security-control-unit-ipcard.json`](safety-security-control-unit-ipcard.json)
  - SSCU capabilities, interfaces, implementation targets, and integration
    information.

The IP card complements the RTL manifest in [`../Bender.yml`](../Bender.yml)
and the design documentation in [`../doc/`](../doc/).
